# Graph compressor

Программа для компактной сериализации неориентированного взвешенного графа
(формат TSV: `id1<TAB>id2<TAB>weight` в каждой строке) в бинарный файл и
обратного восстановления без потерь.

## Сборка

Нужен компилятор с поддержкой C++20, сторонние библиотеки не используются.

```
g++ -std=c++20 -O2 -o run src/*.cpp
```

## Запуск

```
./run -s -i input.tsv -o graph.bin    # сериализация
./run -d -i graph.bin -o output.tsv   # десериализация
```

`output.tsv` содержит те же рёбра, что и `input.tsv`, с точностью до порядка
строк и порядка вершин внутри строки.


Файл `graph.bin` состоит из трёх частей:

1. **Число рёбер** — 4 байта.
2. **Веса рёбер** — по одному байту на ребро в каноническом порядке. Веса
   равномерны на `[0, 255]`, поэтому меньше 8 бит на вес потратить нельзя.
3. **Поток арифметического кодера**, в котором последовательно записаны:
   - **идентификаторы вершин**: отсортированы, кодируются разности между
     соседними id (старшая часть — адаптивной моделью, младшие биты —
     напрямую); размер практически равен теоретическому минимуму
     `log2 C(2^32, N)`;
   - **степени вершин** в порядке возрастания id — адаптивной моделью;
   - **петли** (если есть);
   - **таблица весов модели соседей** (несколько сотен байт);
   - **структура графа**.


## Структура кода

| Файл                     | Назначение                                              |
|--------------------------|---------------------------------------------------------|
| `src/main.cpp`           | разбор аргументов командной строки                      |
| `src/exception.h`        | класс исключения для ошибок ввода-вывода и формата      |
| `src/tsv_io.*`           | чтение и запись TSV и бинарных файлов                   |
| `src/range_coder.*`      | арифметический (range) кодер и декодер                  |
| `src/adaptive_model.*`   | адаптивные частотные модели                             |
| `src/neighbor_coder.*`   | вероятностная модель и кодирование соседей вершин       |
| `src/graph_codec.*`      | формат `graph.bin`: сериализация и десериализация       |
| `check.sh`               | проверка корректности на входном файле                  |
